# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/bedd4ee2-7936-4b45-8769-10c54674c546

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Copy [.env.example](.env.example) to `.env`, then replace `MY_GEMINI_API_KEY` with your Gemini API key.
3. Restart the server and run:
   `npm run dev`
